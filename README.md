# 两张图，整理一条探店视频的制作方案

一张店铺照＋一张产品照，把“想拍点宣传视频”整理成分镜、完整视频提示词和后期口播。

这是 **提示词 Skill，不是视频生成软件**。不会自动登录、生成、扣费或发布，也不附带模型额度。

## 适合谁

餐饮、饮品、零售、生活服务门店，以及帮商家做短视频的创作者。没有两张可读图片时会先指出缺失，不假装看过。

## 安装

在项目根目录运行（已有同名目录时先检查，不覆盖）：

```sh
git clone https://github.com/jay-yangPY/two-image-store-video.git .agents/skills/two-image-store-video
```

在支持该目录的 Codex 环境重新加载。也可直接阅读 SKILL.md 与 references；其他客户端需要按各自文档配置，未逐一实测。

## 第一次怎么用

附上两张有使用权的图片，再发送：

```text
使用 $two-image-store-video。
商家类型：咖啡店；产品名称：冰拿铁。
图片1是店内空间，图片2是产品。
做15秒竖屏视频的制作提示词，不生成视频。
人物使用成年中国顾客，自然手机拍摄感，配音后期制作。
不要编造价格、销量、优惠或实测评价。
```

人物、语言、时长和画幅都可改；不指定时沿用 Skill 的默认值。详见 [输入规则](references/input-and-routing.md)。

## 会交付什么

项目识别、两图用途、创意、时间轴、完整视频提示词、负面约束、后期配音字幕、使用步骤与失败风险。
原稿的默认结构是15秒；指定其他时长时按总时长调整，不硬套五个时间点。

## 使用边界

- 助手需要真实看图能力。本包不包含模型/API/额度。
- 提示词是参考语义，不保证所有视频模型都支持两图引用或负面提示词。提交前核实当前模型版本与入口；没有独立负面栏时将约束整合进主提示词。
- 店铺文字、商品、手部、口型、人物一致性可能失败，生成后仍需检查。
- AI 体验者是虚构演示，不是实际顾客证言。商业使用要有素材权利，并按平台要求标明 AI 制作；不伪造亲测、口碑或功效。
- 本次公开包没有重新生成商家视频，不能把结构检查当成效果保证。
