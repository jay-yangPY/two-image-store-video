# 输入与素材路由

## 输入卡

把用户口语整理成以下字段：

| 字段 | 必需 | 处理规则 |
|---|---:|---|
| 商家类型 | 是 | 如甜品店、咖啡店、餐厅、服装店、美甲店、民宿 |
| 产品名称 | 是 | 使用商家真实名称，不自行改名 |
| 图片1：店铺图 | 是 | 作为门店外景、内景或空间参考 |
| 图片2：产品图 | 是 | 作为产品外观、颜色、包装和配料参考 |
| 产品卖点 | 否 | 只采用用户明确提供或图片可直接验证的事实 |
| 平台 | 否 | 默认抖音、小红书、微信视频号通用 |
| 时长 | 否 | 默认15秒 |
| 画幅 | 否 | 默认9:16 |
| 人物 | 否 | 默认成年外国体验者，衣着自然得体 |
| 风格 | 否 | 默认真实手机实拍、自然探店 |

## 图片检查

检查：

- 店铺主体是否清楚，是否能看出入口、招牌或室内空间。
- 产品是否完整，主体是否清楚，有无严重遮挡。
- 两张图是否属于同一商家或至少不存在明显冲突。
- 图中出现的文字、价格、功效和地址是否可靠可读。

只描述能看清的内容。不确定的招牌文字、品牌信息和配料写成“无法确认”，不得猜测。

## 缺失处理

- 缺一张图片：指出缺少店铺图或产品图，并暂停生成正式提示词。
- 商家类型可从图片可靠判断：自动补全并标注“根据图片判断”。
- 产品名无法确认：只问产品名称，不连续追问其他可默认字段。
- 图片质量一般但仍能识别：继续输出，并在风险中说明参考一致性可能下降。

## 素材映射

在视频提示词开头明确写：

- `图片1作为店铺环境和空间结构的唯一参考。`
- `图片2作为产品造型、包装、颜色和配料的唯一参考。`

不得要求模型把图片1、图片2机械拼接成左右分屏。两张图必须被转译成同一条连续视频中的不同镜头。
